Version 2.1.1 (10-6-26)

New Features

  • Copy Instantly: A new nested option under Extras > Save Screenshots to Clipboard hides macOS's floating screenshot thumbnail, so screenshots save and copy without waiting for it to disappear. Files still save to your screenshot folder. The indented checkbox and down-and-right arrow make its relationship to the parent option clear. Turning either option off or quitting DockAway restores your thumbnail preference; manually re-enabling the thumbnail in Screenshot Options turns Copy Instantly off.
  • Separate Spaces in Onboarding: A native “Displays have separate Spaces” switch in the Desktop Manager card controls the actual macOS setting and stays in sync with System Settings. Your existing choice is preserved, and an inline “Requires log out” notice appears only when logging out and back in is needed to apply a change.
  • Dynamic Desktop Manager Preview: The onboarding preview smoothly switches between separate display sections and a shared All Displays layout as you toggle Separate Spaces. The enlarged preview updates too, letting you see how either choice will look before logging out.

Improvements

  • Adaptive Onboarding: Both setup pages use compact layouts on shorter displays, keeping their navigation controls visible without scrolling.
  • Longer Startup Confirmation: Startup and restart confirmations now stay visible for five seconds instead of 3.5. Confetti clicks reset the countdown, and holding the button keeps it paused.

Bug Fixes

  • Complete Onboarding at Your Own Pace: Granting permissions no longer closes onboarding or skips keyboard navigation setup. Continue advances to the keyboard page, and Get Started completes the tour. Unfinished onboarding also resumes after macOS quits and reopens DockAway during permission setup. If you've completed onboarding before, closing or quitting setup lets DockAway resume as soon as access is restored.
  • Accurate Unavailable Desktop Counts: The Menubar Desktop Indicator shows “? of ?” instead of a misleading “1 of 1” when desktop information is unavailable, including before permissions are granted. Other indicator styles and their previews also show unknown counts appropriately.
  • Correct Start and Restart Messages: Completing onboarding shows “DockAway has successfully started,” even when permission setup required a relaunch. Permission recovery shows “DockAway has successfully restarted.” Confirmations wait until DockAway is ready, and the pill fits either message on one line.
  • Enlarged Preview Closes When You Continue: The enlarged Desktop Manager preview in onboarding no longer stays on screen after you press Return to continue to the keyboard navigation page.

Version 2.1 (10-4-26)

New Features

  • Cycle App Windows: A new option in Dock Preferences > Dock Icon Actions brings the active app's next window forward with each Dock click. Cycles non-minimized windows on the current desktop in a stable order, across displays, without resizing or minimizing them.
  • Automatic Dock Refresh: DockAway automatically restarts only your login's Dock after startup and on quit. Startup waits until permissions are ready and desktop transitions are idle, while quitting restores Dock visibility and respects your Dock preference persistence choices. Other users' Dock processes are untouched.
  • Restart Dock: Restart an unresponsive macOS Dock from the bottom of Dock Preferences without resetting your Dock preferences. Only your current login's Dock is restarted. DockAway pauses its Dock monitoring during the restart and resumes when the replacement is ready. Rich help explains when to use it.
  • Draggable Onboarding Icon: Drag the DockAway icon from onboarding into a permission list in System Settings to add the app. A normal click still plays the shine animation.

Improvements

  • Improved Quick Look Copy Logic: Refined image detection and orientation handling so images copied from Finder's Quick Look paste upright, including in Google Messages. Regular Finder file copies and unrelated images are preserved.
  • Startup Confetti Cooldown: Each confetti click resets a 3.5-second dismissal countdown for the startup confirmation. Holding the button pauses the countdown, and clicking outside still dismisses it immediately.
  • Desktop Change Tooltip Layout: Place Display Name Underneath is now enabled by default when the desktop-change tooltip is enabled. Existing saved layout preferences are preserved.
  • Minor Renames: Made minor wording changes to menu labels for clarity.

Bug Fixes

  • No Gap After the Dock Hides: Fixed an intermittent bottom gap when opening an app from the Dock on an empty desktop. Windows sized to fill the area above the visible Dock now extend into the space it frees when hiding, including delayed launches and restored windows. Smaller windows and manual window sizing are preserved.
  • Dock Visibility on Quit: Quitting saves the shown Dock state, safely restarts only your login's Dock, and verifies that its replacement is shown before DockAway exits. Your Dock preference persistence choices are preserved, and overlapping restart requests are handled safely.
  • Permission Recovery Without Repeating Onboarding: Restoring DockAway's access directly in System Settings no longer requires repeating completed onboarding. DockAway recovers automatically, restarting only when needed, and shows “DockAway has restarted” while preserving your preferences and Pause state.
  • Menu Bar Desktop Indicator: The indicator refreshes automatically after switching desktops to address cases where it disappears on a desktop while DockAway's menu remains accessible through its keyboard shortcut.
  • Uninterrupted Icon Shines: Clicking the onboarding icon plays a complete shine. Additional clicks during the animation are ignored, so the sweep finishes without restarting or queuing extra shines.

Version 2.0 (9-30-26)

New Features

  • Desktop Manager: Manage your desktops directly from the menu bar. See app icons and empty desktops, switch Spaces, create or close desktops, and drag them to reorder or move between displays. Fullscreen apps have their own named tiles and close controls. The grid adapts to your desktops and app icons, with up to five tiles per row, and can be turned off when you prefer a simpler menu.
  • Desktop Manager Keyboard Navigation: Open DockAway with Option+Up or Option+Shift+W, navigate with arrow keys or WASD, and select or close the highlighted desktop. Independent Right Hand and Left Hand profiles support customizable bindings and alternate select and close keys. Hold select on the plus tile to create desktops continuously, or hold close on a desktop for progressively paced deletion. Deleting keeps focus in the same numbered position; close on the plus tile first moves focus back to a desktop.
  • Multi-Display Desktop Controls: Desktops are grouped by display, with active-display indicators and optional cursor teleportation when switching. Choose Numerical or Active First display ordering, with optional Last Used sorting for three or more displays.
  • Menubar Desktop Indicator: Customize desktop numbers with Filled or Outline styles, hierarchical typography, DockAway's blue, white, and green colors, separators, and pill badges. Preview changes live, configure each display independently, and optionally show a compact desktop-change pop-up with adjustable duration and display-name visibility.
  • Activate on Hover: Focus the window under your pointer after an adjustable delay, optionally waiting until the pointer stops moving. Choose whether to bring hovered windows forward, and exclude apps with the Focus Prevention Blacklist.
  • Mission Control Window Actions: Optional hovered-window close buttons and keyboard commands let you close, minimize, quit, or open a selected window directly from Mission Control. Buttons stay hidden during dragging, and app-specific shortcuts can be refreshed from the menu.
  • Open Web Apps & Finder on the Active Desktop: An enabled-by-default option in Advanced settings opens Chromium web apps, Finder, and Trash on your active display and desktop. Clicking Finder or Trash from a display's Dock brings its window to that display without switching Spaces.
  • Extras: New optional settings in DockAway Settings > Extras add everyday window, Finder, clipboard, and sound conveniences:
    • Green Button Fills Window: Bring the clicked window forward and smoothly toggle between filling the display's available area and restoring its remembered size. Windows without a remembered size return to a centered smaller size, and manual resizing becomes the next remembered size. Option-click enters fullscreen.
    • Delete Finder Items with Delete Key: Move selected Finder files and folders to the Trash with Delete alone. Rename fields, search fields, dialogs, and modified shortcuts retain their normal behavior. Holding Delete triggers only one action per key press.
    • Save Screenshots to Clipboard: Automatically copy new screenshots for immediate pasting while keeping the files in your configured screenshot folder. Works with standard macOS screenshot shortcuts and selects the display under your pointer when a capture produces screenshots from multiple displays.
    • Correct Quick Look Copy Orientation: Preserve the displayed orientation of images copied from Finder's Quick Look so they paste right side up. Regular Finder file copies and images copied from other apps are unchanged.
    • Show Sound Icon When Muted: Set Sound to Show When Active in System Settings, then let DockAway switch the native icon to Always Show while muted or at zero volume. It returns to Show When Active when sound is audible, when the option is disabled, or when DockAway quits. Manually changing Sound's visibility disables this option.
    • Lockscreen Lock Sound & Lockscreen Unlock Sound: Independently enable sounds when locking and unlocking your Mac. Both use your current audio output and volume while DockAway is running.
  • Dock Icon Actions: Optional Dock Settings let a click on an application's Dock icon minimize or hide its windows, then restore or unhide them on another click.
  • Pointer Teleportation: Optionally move your pointer to an app's window when a Dock click activates it on another display, or follow a window moved through the green button's Move to Display command.
  • Automatic Mission Control Expansion: Optionally expand the desktop strip as Mission Control opens, leaving the pointer centered on the same display.
  • Theme: Choose Auto, Light, or Dark for DockAway's menus and controls.
  • A Little Sky in About: The About panel features a sky-blue background with painterly clouds.

Improvements

  • Predictive Dock Hiding: DockAway begins hiding the Dock as a non-blacklisted app activates, using cached app classification. Newly opened windows that fill the old Dock-reserved area can expand into the space freed after the Dock hides.
  • Expanded Onboarding: Guided setup now introduces Desktop Manager with an interactive preview and lets you configure keyboard navigation, with both hand profiles enabled by default for new users. Existing users see the new setup once when upgrading to 2.0, with their permissions and preferences preserved.
  • Consistent DockAway Colors: Dock Settings and custom menu controls use DockAway's blue, white, and green palette across appearances.
  • Dock Settings Refinements: Reveal Delay uses evenly spaced 20% checkpoints, and the reset action is clearly labeled Restore Default macOS Dock.

Bug Fixes

  • Permission Checks While Menus Are Open: Completed permission checks are delivered during native menu tracking, preventing a delayed result from incorrectly showing Permission Required.

Version 1.2.1 (9-6-26)

New Features

  • No Hidden Reveal Delay: On its first ready launch, DockAway automatically removes an existing nonzero Dock reveal delay, including delays set by other Dock utilities. This one-time adjustment briefly restarts the Dock, respects managed settings, and leaves later Reveal Delay choices untouched.
  • More Dock Settings, One Click Away: Added “More Dock Settings...” beneath Reveal Delay. It opens the native Desktop & Dock page in System Settings for additional macOS customization.

Improvements

  • Less Work on the UI Thread: Repeated Mission Control Accessibility queries now run on a dedicated background worker. Requests coalesce instead of piling up, obsolete results are discarded, and startup guards keep Dock decisions protected until the initial state is resolved. Animation timings are unchanged.
  • Responsive Permission Checks: Potentially blocking access checks now run off the UI thread. Checks are serialized, timeouts are handled safely, and canceled or outdated results cannot complete setup after it has been interrupted.
  • Restart Only When Needed: The "Continue" button verifies authorization, checks access in the running app, and revalidates authorization before finishing. Setup completes in place when access is usable and monitoring starts successfully. An automatic restart remains a fallback for confirmed access that cannot be activated; missing or unconfirmed authorization keeps onboarding open.
  • Clearer Permission Guidance: Onboarding starts with Accessibility, then checks Input Access. Access that is already available is labeled "Available" and needs no extra switch, even without a separate Input Monitoring entry in System Settings. Input Monitoring instructions appear only when needed. Existing layout and animations are preserved.
  • Keyboard-Friendly Onboarding: The setup window now accepts keyboard focus, allowing its controls and Return and Escape shortcuts to receive normal keyboard input while preserving the existing appearance and animations.
  • More Accessible Blacklist Actions: Choose Application, Remove All, and About Blacklist now provide accessibility press actions and menu action routing. Remove All continues to reflect whether any applications are blacklisted.
  • Native Liquid Glass Sliders: Dock Settings sliders now use the system renderer for their interactive Liquid Glass pills on supported macOS versions. Filled tracks use DockAway blue, while snapping and haptic feedback remain.
  • Small Efficiency Improvements: Blacklist menus reuse live application metadata instead of repeating bundle and icon lookups for the same rows. Permission health checks allow timer coalescing while retaining their existing polling policy.
  • Adaptive Text Colors: Dock Settings slider labels and the disabled Continue button now use system colors that adapt to the current appearance. The Continue button also refreshes its styling when the appearance changes.

Bug Fixes

  • More Reliable Live Permissions: Accessibility and Input Access are now rechecked throughout onboarding, even after a grant and when System Settings was opened separately. Fresh checks replace cached grants, outdated results are ignored, and failed or stalled authorization checks leave Continue unavailable while DockAway retries.
  • Your Dock Shortcut, Respected: DockAway now reads your configured Dock hiding shortcut instead of always sending ⌘⌥D. Disabled or unsupported bindings stop shortcut events and display guidance for restoring the setting.
  • Steadier Dock Decisions: If macOS temporarily cannot provide a window list, DockAway preserves its last confirmed state and retries through its existing checks instead of treating the failure as an empty desktop.
  • Safer Update Downloads: Release automation now gives changed downloads unique filenames and retains previous assets, preventing cached update feeds from pointing to replacement files with different signatures.
