Version 1.1.8 (8-24-26)

  • Seamless Empty-Display Hover Handoff: On multi-display setups, moving the pointer from an occupied monitor onto an empty desktop now routes and shows the Dock automatically without simulating a click or changing focus. Single-display behavior is unchanged.
  • Optional Launch Checks: The automatic check-on-launch behavior introduced in 1.1.6 and removed in 1.1.7 now returns as an optional, off-by-default Check at Launch toggle. It appears above the scheduled Update Frequency choices and, when enabled, quietly checks whenever DockAway opens while keeping the Daily, Every 3 Days, Weekly, or Manual Only schedule as a separate preference.
  • Reliable Update-Available Indicator: The menu now displays "Update Available — v…" whenever Sparkle discovers a new DockAway release, including when automatic downloading and installation are enabled.

Version 1.1.7 (8-23-26)

  • Smoother Fast Desktop Swipes: Fixed a timing race that could make Chrome and Chrome web apps briefly display a black toolbar when rapidly swiping from an empty desktop. DockAway now preserves its fresh destination prediction and hides the Dock before the Space animation begins.
  • Customizable Update Schedule: Automatic Sparkle checks now default to every 24 hours. The new Update Frequency submenu offers Daily, Every 3 Days, Weekly, and Manual Only options, with selections remembered between launches.
  • Launch Update Checks Removed: Removed the automatic update check that ran every time DockAway opened. The next update will give users more control by making launch checks an optional setting.
  • Faster PID and Blacklist Caching: DockAway now caches both positive and negative blacklist results in memory. App launches, quits, and blacklist changes precisely invalidate affected entries, improving performance without retaining stale information.
  • Permission Recovery: DockAway now detects missing Accessibility and Input Monitoring permissions, clearly identifies what is required, and provides direct shortcuts to the correct System Settings page. The Resume button also assists with restoring missing access.
  • Lower Background Overhead: The menu-bar Dock indicator now updates through existing DockAway events instead of using a permanent quarter-second cosmetic polling timer.
  • More Efficient Display Tracking: The lightweight pointer and display timer now includes scheduling tolerance, allowing macOS to combine nearby wakeups while preserving DockAway's responsive 120 ms tracking interval.
  • Quieter Release Builds: Diagnostic transition logs remain available during Xcode testing but are compiled out of release builds, eliminating unnecessary console output and formatting work for users.
  • Updated Menu Preview: The README now includes the latest DockAway menu design, including the Blacklist and Update Frequency controls.

Version 1.1.6 (8-18-26)

  • Update Checks at Launch: DockAway now performs a quiet Sparkle update check whenever it is opened manually or launched automatically at login. Available updates appear through the existing gentle menu-bar reminder without interrupting the user, and the normal six-hour update schedule continues afterward.
  • Smoother Status Animation: The green status dot now uses one uninterrupted animation timeline instead of restarting during routine status refreshes. Its three pulse waves are evenly spaced for a fluid, consistent rhythm with no visible pause at the loop boundary.
  • Faster Blacklist Detection: Blacklist and running-process information is now cached in memory instead of being rebuilt during every window scan. The cache updates immediately after menu changes and app lifecycle events, while a lightweight safety refresh preserves compatibility with the existing Terminal configuration method.
  • Quick Blacklist Access: The current foreground app now appears first in the Blacklist submenu, separated from the remaining applications for faster one-click selection.
  • Accessibility Permission Recovery: If Accessibility access is removed while DockAway is running, monitoring stops safely and the menu clearly displays "Permission Required" with a direct shortcut to Accessibility Settings. DockAway resumes automatically after access is restored.
  • Lower Background Overhead: DockAway now skips unchanged menu updates, stops cosmetic polling while paused, delays recurring helpers until permission is available, reuses static window-filter data, and gives noncritical timers scheduling tolerance so macOS can combine wakeups.

Version 1.1.5 (8-16-26)

  • 94% Idle-Scan Efficiency Improvement: DockAway now uses the event-driven AXObserver notifications instead of continuously performing a full window scan every 0.12 seconds. A lightweight 2-second safety check remains for unusual apps, reducing routine idle scans from about 8.3 per second to 0.5 while retaining fast reactions.
  • Seamless Mission Control: DockAway recognizes when Mission Control is open and temporarily freezes its own Dock decisions so macOS can handle the animation naturally. Downward exits now choose the correct landing behavior: the Dock stays hidden when entering an app and remains continuously visible when returning to an empty or blacklisted desktop.
  • Smarter Desktop Swipes: Direction-aware four-finger tracking and read-only adjacent-Space detection allow empty-to-empty swipes to keep the Dock visible throughout the entire animation. When the destination contains an app, DockAway pre-hides before the Space begins moving, eliminating late Dock slides and greatly reducing Chrome web-app toolbar flicker.
  • Improved Multi-Display Accuracy: Window occupancy is evaluated on the display under the pointer, with fast corrections when the pointer changes displays, a Space changes, or an app's final window is minimized, closed, hidden, restored, or moved.
  • More Efficient Finger Tracking: The main app is notified only when contact crosses into or out of four-finger mode. Once swipe direction is known, unnecessary contact-frame processing stops until the finger count changes, and the old 1/2/3-finger console spam is gone.
  • Sleep, Lock, and Session Awareness: Monitoring timers, trackpad observation, and accessibility observers now stop while the Mac is asleep, the display is asleep, the screen is locked, or the user session is inactive, then rebuild cleanly on wake or unlock.
  • Gentler Sparkle Updates: Automatic update checks now run every six hours, and the menu changes from "Check for Updates" to "Update Available" when a new release is ready without interrupting the user with a background alert.
  • Refined Menu Bar Design: The menu is slimmer and more polished, with a compact glass-style status island, animated pause/resume control, smoothly transitioning green and red status indicators, active-app details, and clearer update and quit icons. When on a desktop, Menu bar will say "Desktop" instead of "App:Desktop". Swiping into an app from mission control now shows the correct app name in the menu bar.
  • Safer Dock Commands: Live Dock-state verification, command tracking, debounce correction, and gesture-specific visibility holds prevent overlapping events from double-toggling the Dock or leaving it in the wrong state.
